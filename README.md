# Book of Strategy

A personal reading library: thirteen author studies and five companion essays, with the foundation and research notes.

The static reader opens from `index.html`. GitHub Pages serves the root of the `main` branch. Search runs entirely in the browser, without analytics or paid services.

The research texts are preserved with their source qualifications and unresolved claims. Original translations, scans and supporting papers remain in the owner's private GitHub archive. Source-shelf links require a GitHub account with access to that archive; the studies themselves are public.

## Updates

This repository is a static export. Edit the corpus and reader in the private source workspace, rebuild with `tools/build-library.mjs`, then run `python3 tools/export-site.py /path/to/empty/export`. Replace this repository's site files with the new export and push to `main` to update the website. Do not copy the private cached source editions into this public repository.

`robots.txt` asks crawlers not to index this personal library; the site is still publicly accessible.
